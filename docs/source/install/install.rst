Installation
============

PyDHN requires Python 3.10 to 3.13. At present, it can only be installed from the `official repository  <https://github.com/idiap/pydhn>`_. Simply run:

.. code-block:: none

   pip install git+https://github.com/idiap/pydhn

To install a specific release, add its tag. For example, for version 0.2.0:

.. code-block:: none

   pip install git+https://github.com/idiap/pydhn@v0.2.0
